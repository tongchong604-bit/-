# 抖音图文参考采集插件设计

## 目标与使用方式
用户使用 Win7 的 Chrome，在自己正常打开、可查看的抖音图文页面点击采集，多篇积累后导出 ZIP，将参考包交给助手分析。无需服务器，不导出登录凭据，不处理视频下载。

## 方案
采用本地 Chrome 扩展，Manifest V3，最低 Chrome 109，面向 Win7 最后官方支持版本 Chrome 109。云端直接抓取目前被访问检查页阻挡；网页书签脚本难以可靠跨域获取原图。扩展仅在用户点击后读取当前页面，使用用户授予的站点访问权限下载公开显示的图片。

## 功能
- 点击“采集当前图文”，识别原链接、笔记ID、作者、正文和配图。
- 优先读取页面已有结构化笔记数据；DOM后备只读取对应笔记容器，避免混入头像、推荐内容和广告。
- 不能可靠识别时明确提示，不用零张图片伪装采集成功；允许用户翻到各张图后再次采集、合并同一笔记。
- 列表显示已采集篇数、图片数、每篇标题，支持删除和清空。
- 导出 ZIP：每篇独立文件夹，含 UTF-8 正文、原链接、元数据和图片；图片保持原格式。失败的图片列入报告，可重试，不把残缺结果称为完整成功。
- 导出前由用户点击开始，完成后交给浏览器下载到本机，文件名不包含路径字符。

## 技术约束
Chrome 109 可用的 JavaScript/API；不使用 sidePanel、offscreen、File System Access API。使用 activeTab、scripting、storage、downloads 权限；图片域名权限只覆盖实际所需抖音官方图片域名，不申请所有网站。导出在扩展页面完成以避免 service worker 生命周期影响。无远程脚本或第三方服务，不读取和导出 Cookie、密码或令牌，不绕过登录、验证码或付费限制。

## 验证与限制
核心提取、去重、文件命名、ZIP完整性、下载失败报告、权限边界均需要测试。当前云端无法稳定打开真实抖音笔记，因此可验证扩展安装结构与离线页面用例；真实 Win7/Chrome109、登录态抖音页面及端到端下载仍需用户实测。不得宣称已验证所有抖音页面。教学文档需提供下载、解压、chrome://extensions、开发者模式、加载已解压扩展和常见失败处理。
