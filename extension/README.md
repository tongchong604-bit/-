# 图文参考采集助手 · Win7 Chrome版（试用版 0.1.1）

本插件运行在你自己的 Chrome 中。你先正常打开抖音图文，然后点击采集，多篇积累后导出 ZIP，把参考包上传到聊天。不需要服务器，不需要把密码交给任何人。

## 安装（只需一次）

1. 下载 `douyin-reference-collector-win7.zip`，用 WinRAR、7-Zip 或系统解压工具“解压到一个文件夹”。不要直接在压缩包里运行。
2. 在 Chrome 地址栏输入 `chrome://extensions` 并回车。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选中解压后含 `manifest.json` 的 `douyin-reference-collector` 文件夹。
5. 点击 Chrome 右上角拼图形“扩展程序”按钮，找到“图文参考采集助手”，可点击图钉固定。

Win7 的官方 Chrome 最高版本为109。本插件要求Chrome109或更高版本，面向Win7的109版本设计；如提示版本不支持，请在 `chrome://version` 查看版本号，不需要把完整设备信息发出来。

## 从0.1.0更新

下载新版并解压，把`douyin-reference-collector`内的文件覆盖到原先加载的插件文件夹，保持原路径不变。打开`chrome://extensions`，点击本插件卡片右下角的圆形箭头重新加载，再刷新抖音标签页。版本应显示0.1.1。不要卸载插件，以免丢失原记录。

## 给账号批量功能提供页面诊断

0.1.1尚不支持整个账号批量采集。为了适配你实际的主页布局，可以先打开目标账号主页，向下滚动让几条作品卡片显示出来，然后点击插件“导出页面诊断（用于适配批量）”。保存`douyin-page-diagnostics.json`，上传到聊天供分析。

诊断仅包含当前页面标题、去掉敏感查询参数的公开链接、图片来源域名（图片路径也会隐藏）、标签/类名、图片位置尺寸与可见性。它不读取Cookie、表单输入、密码、脚本内容或正文。诊断文件会记录公开账号/笔记标识与页面布局，你可以先查看再决定是否分享。

## 自动识别失败：点选当前大图

如果图已经显示，而自动采集提示布局无法识别，请点击“点选当前大图（自动失败时用）”。插件小窗口会关闭，网页顶部出现提示。把鼠标移到要采集的大图上，确认橙色框选中了图片，再点一下。提示保存后，翻到下一张，再次打开插件点选。按Esc可取消。

这种方式一次保存一张，同一笔记会合并，不能宣称已采集整篇或确认原始顺序；正文可能需要手工核对。它不支持从画布、视频帧、blob特殊地址提取原文件，也不会绕过验证页。当前版本不支持批量采集整个账号。

## 怎么采集

1. 在你自己的浏览器正常打开抖音笔记，例如 `https://www.douyin.com/note/7365500792104684834`。需要登录或人工验证时，请正常完成。
2. 等正文和图片显示出来。建议把这篇笔记的全部图片翻看一遍，避免图片还没加载。
3. 点击插件图标 → “采集当前图文”。等到提示已保存，再关闭插件小窗口。
4. 打开下一篇，重复采集。同一篇重复采集会合并图片，刷新可读取的地址，不会增加重复记录。
5. 点击插件 → “查看已采集 / 导出 ZIP”，勾选要导出的笔记，点击“生成所选 ZIP”。
6. 等图片下载完成，再逐个点击“下载这一包”，选择电脑上的保存位置。完成后请查看浏览器下载列表（Ctrl+J），确认每包都已保存。
7. 不用解压，把 ZIP 直接分批上传到聊天。若聊天不支持或拒绝该文件，请按界面限制减少选择后导出；也可解压后分批上传图片和正文。

## 很多图片怎么处理

- 建议每次选3～5篇，不限制只能采集一篇。
- 下载到的图片文件不再压缩；优先选择明确标注的原图地址，但无法保证每个页面都提供原始分辨率。ZIP默认按20MiB分包，分包是各自可解压的普通ZIP，所有分包都要保存并上传。20MiB是本工具的分包设置，不保证任何聊天平台都接受。
- 默认单图最多15MiB，一次导出原图总量最多100MiB。超过时会报告具体失败；请减少每批笔记数量后重试。
- 采集最多200篇，本地记录约4MiB。图片不占扩展存储，只有导出时才下载原文件。
- 保持导出页面打开；已生成的分包只在该页保留，刷新后需重新生成。只有点击每包“下载”后才保存到电脑。

## 导出包有什么

- `参考目录.json`：全部所选笔记的标题、正文、作者、原链接、图片地址、采集提示。
- `导出报告.json`：成功张数、失败列表、是否能确认采集完整。每个分包都带这两个文件。
- 每篇单独文件夹：`正文.txt`，以及`01.jpg`、`02.png`等图片文件，保留原图编码。原文件若为WebP/AVIF也会保留对应格式，Win7图片查看器可能无法预览，可用Chrome打开。

## 失败怎么办

- “未找到图文内容”：确认已进入具体笔记，已登录/完成验证，正文可见；先翻完图片后重试。如果图片已经正常显示，请改用“点选当前大图”。插件不会绕过登录和验证。
- “无法确认完整张数/顺序”：目前只读到了页面中的已加载配图。请核对原笔记，多翻图后重复采集，不要把它当成完整结果。
- “图片请求失败”：图片地址可能已过期，或站点不允许下载。重新打开原笔记并采集后重试；失败地址和原因在报告中，不会伪装成完整成功。
- “图片域名不在允许范围”：本版只允许四类抖音常用图片域名；请提供笔记链接和报错，不要提供Cookie或密码。
- “未读取正文”：核对原笔记，手工补充正文，或反馈具体笔记链接与截图。
- 如果整篇始终不能读取：可能是页面布局与当前解析方式不匹配，请提供页面截图和插件错误文字，以便改进。
- ZIP打开后没有图片：先读导出报告。如果全部下载失败，包里仍会保留正文和错误报告，不代表成功导出了图片。

## 权限与本地数据

- `activeTab` / `scripting`：只在你点击时读取当前抖音页，不常驻采集其他网页。
- `storage`：将笔记元数据存到本机扩展存储。
- `downloads`：将你选择的ZIP保存到电脑，浏览器可能弹出位置选择框。
- 图片访问范围仅为HTTPS下的`douyinpic.com`、`byteimg.com`、`ibytedtos.com`、`pstatp.com`及其子域名。下载请求不携带账号Cookie，不需要密码。
- 不自动向外部服务上传文件，不读取Cookie、密码、令牌。导出包含你采集的正文、作者及图片临时地址，分享前请确认内容。
- 点击“清空记录”会询问确认，只删除插件本地记录，不影响已经下载的ZIP；卸载插件通常也会删除本地记录。
- 仅供有权查看的内容整理和学习参考，公开发布他人图片前需要确认使用授权。

## 验证范围

本版已测试离线页面中的笔记匹配、推荐图排除、重复合并、HTTP原图下载、失败报告、ZIP中文文件名和大小分包。当前云端无法稳定读取真实抖音页面，因此不保证支持所有笔记布局。Win7/Chrome109的真实安装、登录态抖音采集和下载效果，仍需要你安装后试用确认。
